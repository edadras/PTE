## ۲. اعمال محدودیت (Quota Enforcement)

```php
final class QuotaGuard
{
    public function check(string $metric, int $amount = 1): QuotaResult
    {
        $academy = TenantContext::require();
        $limit   = $academy->plan->limits[$metric] ?? null;

        if ($limit === null) return QuotaResult::unlimited();

        $used = Redis::get("ac{$academy->id}:quota:{$metric}:".now()->format('Y-m')) ?? 0;

        return match (true) {
            $used + $amount > $limit => QuotaResult::exceeded($used, $limit),
            $used / $limit >= 0.95   => QuotaResult::critical($used, $limit),
            $used / $limit >= 0.80   => QuotaResult::warning($used, $limit),
            default                  => QuotaResult::ok($used, $limit),
        };
    }
}
```

### رفتار در هر متریک

| متریک | رفتار در سقف |
|-------|--------------|
| `active_students` | ثبت‌نام جدید مسدود، دانشجویان موجود بدون اختلال |
| `ai_requests` | نمره‌دهی AI متوقف؛ تمرین‌های الگوریتمی فعال می‌مانند |
| `asr_minutes` | Speaking غیرفعال با پیام واضح |
| `storage_mb` | آپلود جدید مسدود |
| `staff_users` | دعوت جدید مسدود |
| `broadcasts` | ارسال گروهی مسدود |
| `questions` | افزودن سوال مسدود |

**اصل:** محدودیت هرگز نباید داده موجود را از بین ببرد یا سرویس را کاملاً بخواباند. همیشه یک مسیر کاهش‌یافته اما کارآمد باقی بماند + پیام روشن «برای ادامه، پلن را ارتقا دهید».

## ۳. چرخه صورتحساب

```
trialing ──(پرداخت)──▶ active ──(عدم پرداخت)──▶ past_due ──(۷ روز)──▶ suspended
    │                    │                          │                    │
    └──(۱۴ روز)──▶ expired│                          └──(پرداخت)──▶ active│
                          └──(لغو)──▶ canceled ──(پایان دوره)──▶ expired  │
                                                                          │
                                            (۳۰ روز بعد) ──▶ حذف داده ◀────┘
```

- **یادآوری:** ۷ روز، ۳ روز و ۱ روز قبل از سررسید (ایمیل + بنر پنل)
- **past_due:** پنل read-only، ربات فعال (دانشجو نباید تاوان بدهد)
- **suspended:** ربات پیام «سرویس موقتاً غیرفعال است» می‌دهد
- **حذف:** فقط پس از ۳۰ روز و پس از ارسال لینک Export کامل داده

## ۵. فروش داخل ربات (B2C)

جریان خرید دانشجو:

```
💳 خرید دوره
   ↓

│ 📦 پلن‌های English First          │
│                                  │
│ 🥉 پایه — ۱ ماه                  │
│    ۹۹۰٬۰۰۰ ریال                  │
│    ۵۰ تمرین · بازخورد AI          │
│                                  │
│ 🥈 حرفه‌ای — ۳ ماه                │
│    ۲٬۴۰۰٬۰۰۰ ریال                │
│    نامحدود · ۲ آزمون Mock         │
│                                  │
│ 🥇 ویژه — ۶ ماه                   │
│    ۴٬۲۰۰٬۰۰۰ ریال                │
│    نامحدود · Mock نامحدود         │
│    تصحیح دستی مدرس                │
└──────────────────────────────────┘
   ↓ انتخاب
[لینک پرداخت] یا [Telegram Payments]
   ↓ callback درگاه

```

قابلیت‌های فروش برای آموزشگاه:
- کد تخفیف (درصدی/مبلغی، محدودیت تعداد و تاریخ)
- پاداش معرفی دوست (Referral) — هر دو طرف اعتبار می‌گیرند
- خرید تک‌آزمون
- تمدید خودکار (Stripe/Telegram)
- **کارمزد پلتفرم:** اگر آموزشگاه از درگاه شما استفاده کند، مثلاً ۳٪ — یک جریان درآمدی دوم که با رشد مشتری مقیاس می‌گیرد

## ۶. اقتصاد واحد (Unit Economics)

پیش از تثبیت قیمت، این محاسبه باید با داده واقعی انجام شود:

```
هزینه ماهانه به‌ازای هر دانشجوی فعال
──────────────────────────────────────────────
تمرین: ۲۰ در ماه
  ۱۲ الگوریتمی           →  $0.000
  ۸ نیازمند AI
     ASR (۴۰ ثانیه)       →  8 × $0.004  = $0.032
     نمره‌دهی (Flash)      →  8 × $0.006  = $0.048
آزمون Mock: ۱ در ماه
     ~۲۰ سوال AI (Pro)    →  20 × $0.02  = $0.400
ذخیره‌سازی (~۵۰MB)        →              = $0.001
──────────────────────────────────────────────
جمع                                     ≈ $0.48
```

با آموزشگاهی که ۲۰۰ دانشجوی فعال دارد: **~$96/ماه** هزینه AI. اگر پلن Professional حدود $150 باشد، حاشیه سود قبل از زیرساخت ~۳۵٪ است.

**درس‌های این محاسبه:**
1. آزمون Mock بیشترین هزینه را دارد → باید در پلن‌های پایین محدود شود
2. مسیریابی به Flash برای تمرین، تفاوت سود و زیان است
3. سقف AI باید بر حسب **درخواست** باشد نه فقط تعداد دانشجو
4. برای مشتری بزرگ، BYOK بهترین گزینه است — ریسک را حذف می‌کند

### هشدار سودآوری
Job روزانه: برای هر آموزشگاه، `هزینه AI ماه جاری / درآمد ماهانه از او`. اگر > ۵۰٪ → هشدار در پنل Super Admin. این تنها راه جلوگیری از کشف زیان در پایان ماه است.

## ۷. مالیات و انطباق
- محاسبه و نمایش مالیات بر ارزش افزوده روی فاکتور (قابل تنظیم به ازای کشور)
- تولید فاکتور رسمی PDF با شماره ترتیبی و اطلاعات حقوقی آموزشگاه
- نگهداری سوابق مالی ۷ سال (الزام قانونی متداول)
- Webhook درگاه‌ها همیشه با امضای رمزنگاری‌شده اعتبارسنجی شود
- هرگز اطلاعات کارت روی سرور شما ذخیره نشود — همیشه ریدایرکت به درگاه
