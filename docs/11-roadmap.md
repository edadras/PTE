```
✓ مخزن Laravel 12 + PHP 8.4 + ساختار Domain
✓ Docker Compose برای توسعه محلی (MySQL, Redis, MinIO, Mailpit)
```

> **این فاز را کوتاه نکنید.** هر روزی که اینجا صرفه‌جویی شود، ده روز در فاز ۳ هزینه می‌دهد.

## فاز ۵ — اپ موبایل (۸ هفته)

```
هفته ۱–۲  اسکلت Flutter + احراز هویت + برندینگ پویا
هفته ۳–۴  تمرین‌ها + ضبط صدای بومی با کیفیت بالا
هفته ۵–۶  حالت آفلاین + همگام‌سازی
           Push Notification (FCM/APNs)
هفته ۷–۸  انتشار در Google Play و App Store
```

### تصمیم مهم: یک اپ یا اپ به‌ازای هر آموزشگاه؟

| گزینه | مزیت | عیب |
|-------|------|-----|
| **A. یک اپ مشترک با برندینگ پویا** | یک بار انتشار، به‌روزرسانی آسان | برند آموزشگاه در فروشگاه دیده نمی‌شود |
| B. اپ اختصاصی هر آموزشگاه | White Label کامل | انتشار و نگهداری N اپ، بازبینی فروشگاه‌ها، کابوس عملیاتی |

**توصیه: گزینه A** برای همه، با گزینه B فقط به‌عنوان سرویس پولی Enterprise (با فرایند build خودکار از یک کدبیس و فایل کانفیگ برند).

## ۵. اولین ۳۰ روز — دقیقاً چه کاری

اگر فردا شروع کنید:

```
روز ۱–۲    راه‌اندازی مخزن، Docker Compose، CI
روز ۳–۵    ساختار Domain، TenantContext، BelongsToAcademy
روز ۶–۸    Migrationهای پایه + RBAC + تست‌های جداسازی
روز ۹–۱۲   دو Panel در Filament + احراز هویت + انتخاب آموزشگاه
روز ۱۳–۱۵  استقرار staging + Sentry + Horizon + Backup
────────── پایان فاز ۰ ──────────
روز ۱۶–۲۰  جدول telegram_bots + اتصال توکن + Webhook + Idempotency
روز ۲۱–۲۴  ProcessTelegramUpdate + Sender با Rate Limiter + BotHealth
روز ۲۵–۳۰  students + telegram_identities + /start + منوی ثابت اول
```

**در پایان روز ۳۰ باید بتوانید:** یک آموزشگاه بسازید، توکن ربات بدهید، و ربات به `/start` با منو پاسخ دهد.

اگر روز ۳۰ به اینجا نرسیدید، مشکل در برآورد نیست — در Scope است. برگردید و کم کنید.
